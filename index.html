Personal Backup

Личный инструмент для резервного копирования моих файлов в Google Drive.

Политика конфиденциальности

Приложение используется только владельцем. Доступ к Google Drive нужен для загрузки, просмотра и удаления резервных копий. Данные не передаются третьим лицам. Токены доступа хранятся на сервере владельца.

Условия использования

Приложение предназначено исключительно для личного использования владельцем.
